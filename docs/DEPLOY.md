# الرفع على الموقع

المشروع مربوط بـ **Vercel** (مشروع `octopus`) وبـ **GitHub**
(`basildraz-arch/octopus`، فرع `master`). الرفع = تعمل commit وتـpush،
وVercel بيبني لوحده.

---

## الخطوات

افتح PowerShell في مجلد المشروع ونفّذ بالترتيب:

```powershell
cd C:\Users\LOGO\Desktop\octopus

npm run build
```

**⚠️ ما تكمّلش غير لو الـbuild عدّى.** ده أهم سطر في الملف ده — الساندبوكس
بتاعي مش بينزّل حزم فما قدرتش أعمله، وأي خطأ في الأنواع هيظهر هنا مش قبل كده.
لو طلع خطأ، ابعتهولي زي ما هو قبل ما تدوس أي حاجة تانية.

ولو عدّى:

```powershell
git add .

git commit -m "per-module pricing, referrals, plan limits, data export, grouped settings"

git push origin master
```

بعدها Vercel بيبدأ يبني لوحده. تابع من `vercel.com` → مشروع `octopus`.

---

## قبل ما ترفع: راجع الـEnvironment Variables على Vercel

ملف `.env.local` **مش بيترفع** (مقفول في `.gitignore`)، فأي مفتاح لازم
يكون متسجّل في Vercel نفسه. افتح:

**Vercel → octopus → Settings → Environment Variables**

واتأكد إن دول موجودين في **Production**:

| المفتاح | لو ناقص هيحصل إيه |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | الموقع مش هيفتح خالص |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | الموقع مش هيفتح خالص |
| `SUPABASE_SERVICE_ROLE_KEY` | **كل صفحات Master تقع** — الموافقات، الأكواد، الباقات، حسابات الموظفين |
| `GEMINI_API_KEY` | الأخطبوط الذكي يرمي خطأ |
| `SIGNUP_INVITE_CODE` | محدش يقدر يسجّل حساب جديد |
| `PAYMOB_*` (4 مفاتيح) | الدفع أونلاين مش هيشتغل |

**`SUPABASE_SERVICE_ROLE_KEY` هو أخطرهم.** نص الفيتشرز الجديدة بتمر عليه.
لو مكانش متسجّل على Vercel من قبل — سجّله دلوقتي.

## بعد الرفع: خمس دقايق تتأكد

١. افتح الموقع وسجّل دخول بحسابك.
٢. `/master` — لازم تشوف الخمس بيزنسات وأسعار القوايم والإحالات.
٣. `/settings` — لازم تشوف تلات مجموعات، وجوه "محلك" زرار **تصدير بياناتك**. نزّل ملف الأصناف واتأكد إن العربي طالع صح في إكسل.
٤. `/sales` — اعمل بيعة واحدة لصنف عنده مخزون، وبعدين افتح `/items` واتأكد إن **الكمية نقصت فعلًا**.
٥. اسأل الأخطبوط سؤال بسيط — لو رمى خطأ، شوف اسم الموديل في `lib/gemini.ts`.

الخطوة رقم ٤ هي الأهم. قاعدة البيانات اتغيرت كتير، والبيعة دي بتتأكد إن
الكود الجديد والقاعدة الجديدة ماشيين مع بعض.
